# Akash Joseph — Premium Editorial Portfolio

A bespoke, art-directed personal portfolio website for **Akash Joseph** (UI/UX Designer & Front-End Developer), crafted with an **Editorial Minimal + Interactive** aesthetic inspired by Swiss typography, contemporary graphic design studios, and high-end digital monographs.

---

## ✦ Creative Direction & Design System

- **Palette**:
  - `Background (#F4F2ED)`: Warm archival paper / tactile canvas
  - `Primary Text (#171717)`: High-density carbon
  - `Secondary Text (#77746D)`: Editorial slate neutral
  - `Muted Surface (#EAE8E1)`: Soft stone structural tone
  - `Borders (#D9D6CE)`: Hairline architectural rules
  - `Accent (#A8B7A3)`: Subdued natural sage, deployed with restraint
- **Typography**: Swiss typographic scale with strict baseline grids, high contrast editorial headlines, controlled reading measure (65ch), and monospace technical metadata.
- **Micro-Interactions**: Fluid Framer Motion transitions, interactive system switcher, subtle image hovers, and strict `prefers-reduced-motion` compliance.

## ✦ Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v26)
- npm 9+

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
